# Space imagery and 3D model: sources

| File | What it is | Source |
| --- | --- | --- |
| `assets/models/emu-nasa.glb` | 3D model of the EMU spacewalk suit | NASA 3D Resources, "EMU" (github.com/nasa/NASA-3D-Resources). NASA: "free and without copyright". Edited for the app: jetpack removed, arms lowered to the sides, gray gloves, textures compressed. The NASA marks are replaced in code by the AstroVital logo and name plate; the gold visor and colors are set in code. |
| `earth-day.jpg` | Earth by day | NASA Blue Marble (NASA Earth Observatory / Visible Earth), copy distributed with the three-globe project |
| `earth-lights.jpg` | Earth city lights at night | NASA Earth at Night imagery, copy distributed with the three.js examples |
| `earth-clouds.jpg` | Cloud layer | three.js examples (planet textures) |
| `mars.jpg` | Mars surface map | NASA 3D Resources, "Images and Textures / Mars" |
| `moon.jpg` | Moon surface map | three.js examples (planet textures). Its original source was not confirmed by the team; NASA's CGI Moon Kit (SVS) is a drop-in replacement. |

Code: three.js (MIT License, see `js/vendor/LICENSE-three.txt`).
Stars are generated in code (they are not a real star map).
